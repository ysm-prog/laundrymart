# Coding Standard

- Follow the repository's existing language and framework conventions unless they are demonstrably harmful.
- Prefer explicit, readable code.
- Use strong typing where supported.
- Keep functions focused.
- Avoid magic values and unexplained side effects.
- Remove dead code only after verifying it is unused.
- Do not duplicate business rules.
- Avoid premature abstraction.
- Keep error handling intentional and user-safe.
