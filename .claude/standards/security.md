# Security Standard

- Enforce authorization server-side.
- Validate untrusted input at boundaries.
- Never commit secrets.
- Do not log credentials, tokens, or unnecessary personal data.
- Use least privilege.
- Treat uploaded files and external content as untrusted.
- Review injection, access-control, session, and data-exposure risks.
- Keep security controls close to the boundary they protect.
- Prefer established libraries and framework protections over custom cryptography or security primitives.
