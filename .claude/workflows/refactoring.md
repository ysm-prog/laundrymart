# Refactoring Workflow

1. Identify the behaviour that must remain unchanged.
2. Establish a baseline with available tests and checks.
3. Find duplication, complexity, coupling, or unclear ownership.
4. Choose one cohesive refactoring target.
5. Make small changes.
6. Run verification after each meaningful step.
7. Remove obsolete code only after confirming it is unused.
8. Avoid mixing feature changes with broad refactoring.
9. Record architectural changes when they affect project structure.

Apply `.claude/standards/coding.md` and `.claude/standards/testing.md` throughout.
